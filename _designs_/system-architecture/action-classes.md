# Action classes

The classes [action-policy](action-policy.md) confirms; a class applies when its trigger matches the target or text.

| Class | Detected when (target or text) |
|---|---|
| `submit` | click, or a Return (`ENTER` or a typed newline), on a control or field named like send, post, submit, publish, reply, sign up, or that reaches people or commits shared work (call, join meeting, accept invitation, tweet, approve, merge, deploy; CU-261 - a bare Accept, Join or Follow stays free); a bare Reply is free only when every entry there was read empty; 16-17 Nov: an IDE's Sync Changes, a push with an object (Push tags, Push branch to remote), and a sequence whose last step is push, whatever the steps before it ('Fetch, then push', 'Reword, then push'), or a trailing sync after a git verb or with a git object ('Edit, then sync' stays free; CU-403, CU-597); Mail's Bounce and Redirect (CU-399); messages to event guests (Email guests; CU-397); 17-18 Nov, in seven locales: publish and post (CU-617), call and join meeting (CU-619), leave group and unsubscribe (CU-621; Dutch newsletter opt-outs CU-624, French 'Quitter ce groupe' #1043), and Chinese 退订 alone or with a mail object (CU-628) |
| `purchase` | named like buy, pay, order, checkout, subscribe, donate; a Return in a form whose submit is named so; 16-17 Nov: money moved out to a bank or card ('Send to bank'; CU-413); a paid boost, promote or sponsor of a post (CU-404); 18 Nov: cancelling or ending a membership or plan, and ending, terminating or stopping a subscription, in English and seven locales, a closed-list adverb inside keeping the class (CU-625, CU-628, CU-629; the cancel-delete / end-purchase split follows the policy owner's twin-parity rule of 18 Nov, which cu-coordinator is asked to confirm); turning a subscription's auto-renew off stays free in English, German and French, a domain's asks on a registrar page (CU-410, CU-537); the Chinese off forms still ask purchase, an over-ask (CU-631, open) |
| `delete` | named like delete, remove, discard, erase, empty bin, clear history, reset settings, uninstall, replace, overwrite, don't save, or trash on a button; Backspace or Delete on a focused list, alone or with Shift, Option or Control; Command-Delete; Command-D while a sheet is up, extra modifiers too (CU-234); 16-17 Nov: a Force push (CU-403); a drag onto a trash, deleted-items or junk folder, whole names in English and the locales of #910 / #919 / #954 (Ukrainian since CU-594, closed live on 17 Nov) (CU-385, CU-594); Command-D with the sheet or dialog itself focused, by role or subrole (CU-364; a Save As file sheet's Command-D reads delete too, an over-class: CU-598); 18 Nov: cancelling a subscription, a closed-list adverb inside keeping the class (CU-625, CU-629); factory reset in any word order and language (CU-620), return / revert to factory settings too (CU-622, CU-623) |
| `permission` | sharing, invite, revoke, permission, API key or account-security controls; standing choices such as Always Allow, Don't ask again, Set as Default, Always use this app, Finder's Change All (CU-258; a bare Allow stays free, except on a consent page or access dialog, CU-393); storing a credential - Save password, Save or Create passkey, Remember password, Save login, Never save (CU-289; Remember me and a plain Save stay free); switching account protection off - turn off, disable, remove or allow with 2-step, 2FA, passkeys, login alerts, recovery, Find My (CU-270); turning on a camera or microphone, unmute (CU-261); 16-17 Nov: a web drag onto a shared or public space, whole names only - shared / public spaces plus 'Public Files / Docs / Assets / uploads ...' and 'Shared with partners / clients / the team' since CU-593 (closed live on 17 Nov); desktop drags stay as main (CU-385, CU-593); a bare Allow, Continue or Accept on an OAuth consent page or in an access-request dialog (CU-393); presenting, broadcasting or recording (CU-396); shared-drive moves, viewer download / print / copy and letting others edit (CU-425); adding a collaborator (CU-403); Mail's Apply Rules and Outlook's Run rules (CU-399); 17-18 Nov, in seven locales: sharing a location and granting access (CU-616), share and invite (CU-617), signing out of all devices (CU-621) |
| `credential` | `type`, paste or drag text into a password, `one-time-code` or `cc-*` field or a text entry named password, passcode, passphrase, PIN or access code (CU-606; English only - the locale access codes read sensitive_data with the locale password words, the split CU-607 awaits a ruling on) (a drag: live 20261108T004654Z-448b9d), or one the run saw as a password field, shown in plain text ([password-memory](password-memory.md); live 20261108T021023Z-e7ec71, 234243Z-121a27), or a `{{secret:name}}` placeholder |
| `sensitive_data` | `type`, pasted or browser-dragged text matching card, IBAN, routing-and-account, national or tax id, phone, e-mail, key, 0x-key or recovery-phrase patterns, a URL carrying it (R29), typing, pasting (any Paste route) or dragging text into a text entry named for a bank account, tax id, secret or identity detail (e.g. recovery phrase, one-time code, passport number; `policy.mjs` name lists), text pasted or dragged from such a field, or copied or dragged from shown text captioned so ([copy-source](copy-source.md), [copy-caption](copy-caption.md), [drag-text](drag-text.md); live 20261108T004646Z-a15df9, 012741Z-5a5f14), or a desktop paste not copied by the run ([paste-consent](paste-consent.md)) |
| `new_site` | `navigate` to an origin the site filter answers `not_allowed`; approval adds it for the run |
| `page_dialog` | `ENTER` or `type` while a `confirm`, `prompt` or `beforeunload` dialog is held, a page's permission request or download; the request carries its text and a screenshot; a model keypress alone accepts nothing |
| `install` | file-run prompts (refused by the driver); 16-17 Nov: an app updater's Update Now, Install Update, Update and Restart or Download and Install, desktop only (CU-407) |
