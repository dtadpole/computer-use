  nothing in `/tmp`.

- **Every pass:** the whole inbox; the Verify queue; armed launchers alive; the run lock; my PRs' mergeability (D-085).

  when a build started first. Test the filed shape exactly - a button name can ask by itself (CU-814).

  named for the review; my own held-outs and negated / past / conditional twins in every language a PR adds. A new head voids an OK.
- **Closes:** rows on the merge, then mutants in a scratch tree. A mutant counts only when its row fails, the file
  parses and its anchor is unique; a survivor is named redundant only after it misses every row.
- **Open:** the 26 Nov CU-763 close on helper 0.2.75 (the exclusion record, no settings app opened) and CU-752;
  #1486 (CU-788) after its r3 cut; CU-814's PR; CU-821 with CU-823; CU-794 and CU-791's live row wait for a fixture
  that reaches the front-app stop; step 4 with the owner (CU-11, CU-727).
- **Lessons:** rows start only in a written window naming me, and DONE leaves before that window ends - let the job
  send it. Never stop a launcher whose window is open. Fixture apps only for desktop runs; the signed node first on
  PATH for anything that talks to the helper.
