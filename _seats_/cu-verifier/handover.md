# [cu] Verifier - Handover

Start with [responsibilities](responsibilities.md) and [verdict](ultimate-goal-2-verdict.md).

- **Where:** a private tools folder inside the session worktree (git-ignored; launchers, pages, logs, notes) and
  detached test trees beside it; nothing in `/tmp` (macOS clears it).
- **Push:** gate unpiped, push on exit 0; one action-log line per PR; a PR title names no filing id but 'Part of CU-16'.
- **Every pass:** the whole inbox; the Verify queue; armed launchers alive; the run lock; my PRs' mergeability (D-085).
- **Reviews:** a policy probe of the head (node only, both routes) first, then whole-page live rows in the window
  named for the review. Over-ask rows before any OK: negated, past / completed and near rows in every language a PR adds.
- **Closes:** one serial watcher over the armed PRs; rows on the merge, then mutants in a scratch tree. A mutant counts
  only when its row fails, the file parses and its anchor is unique.
- **Open:** #1475 (CU-805) r2 after the marker table; CU-806, CU-807; the 26 Nov CU-763 close on helper 0.2.75 (the
  exclusion record, no settings app opened) and CU-752; CU-794 waits for a fixture that reaches the front-app stop;
  step 4 with the owner (CU-11, CU-727).
- **Lessons:** browser rows are held until headless Chrome can raise no system notification (CU-808). Read the Verify
  state before `verified`. Rows start only in a written window naming me - never another seat's, never while a gate
  runs; a launcher whose wait ends without its window exits. A filed desktop row is never 'covered' by web rows. Fixture
  apps only for desktop runs; the signed node first on PATH for anything that talks to the helper.
